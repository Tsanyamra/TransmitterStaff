# TransmitterStaff

TransmitterStaff enables real-time-processing, context-aware data aggregation through scalable, cloud-based architecture and RESTful API access.

With TransmitterStaff, you get a lightweight tool that stays out of your way.

**What you get**

- TransmitterStaff enables real-time-processing, context-aware data
- aggregation through scalable, cloud-based architecture
- and RESTful API access

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/TransmitterStaff.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure TransmitterStaff, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
